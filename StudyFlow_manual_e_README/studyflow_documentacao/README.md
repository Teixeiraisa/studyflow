# StudyFlow

Aplicativo de organização de estudos desenvolvido com Flutter e Dart.

## Funcionalidades
- Cadastro e login de usuários com Firebase Authentication.
- Cadastro e gerenciamento de matérias.
- Cadastro e gerenciamento de tarefas e provas.
- Calendário e agenda de estudos.
- Persistência de dados com Cloud Firestore.

## Tecnologias
Flutter, Dart, Firebase Authentication, Cloud Firestore, HTML, CSS, Git e GitHub.

## Como executar
1. Instale e configure o Flutter SDK.
2. Abra a pasta do projeto no VS Code ou Android Studio.
3. Na raiz do projeto, execute `flutter pub get`.
4. Confira a configuração Firebase para a plataforma desejada.
5. Inicie um emulador ou conecte um dispositivo.
6. Execute `flutter run`.

## Manual técnico
O manual HTML/CSS está na pasta `manual/`. Abra `manual/index.html` no navegador para consultar localmente.

## Banco de dados
O aplicativo utiliza Firebase Authentication para autenticação e Cloud Firestore para persistência. Os dados devem ficar organizados por usuário e protegidos por regras de segurança no Firestore.
