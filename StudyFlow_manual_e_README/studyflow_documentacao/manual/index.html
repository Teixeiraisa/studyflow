01 · VISÃO GERAL

Apresentação do aplicativo

O StudyFlow é um aplicativo de organização acadêmica desenvolvido com Flutter e Dart. Seu objetivo é ajudar estudantes a reunir matérias, tarefas, provas e compromissos de estudo em um só lugar.

▤

Matérias

Cadastro de disciplinas e informações dos professores.

✓

Tarefas

Registro, consulta, edição e exclusão de atividades.

▦

Calendário e agenda

Visualização de datas e planejamento de estudos.

Público-alvo: estudantes que desejam organizar suas atividades e acompanhar seus prazos escolares.

03 · COMEÇAR

Requisitos e instalação

Requisitos

  • Flutter SDK instalado e configurado.
  • Dart, incluído na instalação do Flutter.
  • Visual Studio Code ou Android Studio.
  • Git instalado para clonar o repositório.
  • Acesso à internet para usar os serviços do Firebase.
  • Configuração Firebase válida incluída no projeto.

Passo a passo

  1. Obter o projeto.

    Clone o repositório do GitHub ou baixe seus arquivos e abra a pasta principal no editor.

  2. Instalar as dependências.

    Abra o terminal na raiz do projeto e execute:

    flutter pub get
  3. Verificar a configuração.

    Confira se os arquivos de configuração do Firebase correspondem ao projeto utilizado.

  4. Executar o aplicativo.

    Com um emulador ou dispositivo conectado, execute:

    flutter run
Importante: os comandos devem ser executados na pasta que contém o arquivo pubspec.yaml. Para compilar para uma plataforma específica, ela precisa estar configurada no ambiente Flutter.

06 · PERSISTÊNCIA

Autenticação e banco de dados

O Firebase Authentication gerencia as contas e a entrada dos usuários. O Cloud Firestore armazena os registros de cada usuário, permitindo que os dados persistam entre execuções.

Estrutura de dados

users/
└── {uid}/
    ├── nome
    ├── email
    ├── subjects/
    │   └── {subjectId}
    │       ├── nome
    │       ├── professor
    │       └── cor
    └── tasks/
        └── {taskId}
            ├── nome
            ├── materia
            ├── tipo
            ├── data
            └── concluida

Os campos acima refletem os registros usados nas telas de matérias e tarefas. Verifique no Firebase Console os campos efetivamente gravados antes de alterar este esquema. A agenda pode usar uma coleção adicional, conforme a implementação final.

Segurança: as regras do Firestore devem restringir a leitura e a escrita aos dados do usuário autenticado. Nunca publique senhas, tokens privados ou chaves secretas no manual ou no repositório.

07 · OPERAÇÕES

Como gerenciar informações

C

Cadastrar

Abra a seção desejada, escolha a opção de adicionar, preencha os campos e salve.

L

Consultar

Os registros salvos são apresentados na lista correspondente.

E

Editar

Selecione a opção de edição do registro, altere os dados e salve as mudanças.

X

Excluir

Use a opção de exclusão do registro e confirme, se a tela solicitar.

Essas operações correspondem ao CRUD: Create, Read, Update e Delete. Antes da entrega, teste cada operação com dados de exemplo e confirme se as alterações aparecem no Firestore.

08 · MANUTENÇÃO

Como alterar o projeto

Alterar as cores

Procure as cores definidas em ThemeData no arquivo lib/main.dart e as cores específicas nas telas. A cor roxa principal utilizada atualmente é Color(0xFF5E35B1) e o fundo é Color(0xFFF5F3FA). Ao alterar a paleta, confira botões, ícones, campos e textos para manter contraste e consistência.

Trocar a logo

Substitua o arquivo assets/logo_studyflow.png mantendo o mesmo nome e formato, ou altere o caminho no Image.asset da tela de login e na declaração de assets do pubspec.yaml. Depois execute flutter pub get e reinicie o app.

Alterar o nome do aplicativo

O texto exibido na interface pode ser alterado nos arquivos de tela, como login_page.dart e main_navigation.dart. O nome exibido no dispositivo também pode depender das configurações específicas de Android ou iOS.

Adicionar ou alterar uma tela

Crie um arquivo Dart em lib/screens/, implemente a tela com Flutter e importe o arquivo onde a navegação é definida, atualmente main_navigation.dart. Conecte os botões e teste a navegação em diferentes tamanhos de tela.

Adicionar um campo ao banco

Localize o formulário que cadastra o registro e inclua o novo campo. Depois, atualize a gravação no Firestore e todas as telas que leem ou editam esse registro. Se o campo precisar de validação, adicione-a ao formulário. Teste registros novos e antigos, pois os registros antigos podem não possuir o novo campo.

Gerar uma nova versão

Execute os testes e verifique o projeto com flutter analyze. Para gerar uma versão Android em formato APK, execute flutter build apk. O arquivo de saída costuma ficar em build/app/outputs/flutter-apk/. A distribuição e assinatura de uma versão final podem exigir configuração adicional.

09 · SUPORTE

Solução de problemas comuns

O pacote ou asset não é encontrado

Confira o caminho e a indentação do pubspec.yaml, salve o arquivo e execute flutter pub get.

O login não funciona

Confira a conexão com a internet, as credenciais, a confirmação do e-mail e se o provedor E-mail/Senha está habilitado no Firebase Authentication.

Os dados não aparecem

Confirme se o usuário está autenticado, se a coleção e os campos correspondem ao código e se as regras do Firestore permitem a operação.

O seletor de data apresenta erro de localização

Confira as configurações de localização no MaterialApp em main.dart e as dependências de localização do Flutter. As telas que usam datas também precisam respeitar essas configurações.

O aplicativo não inicia

Leia a primeira mensagem de erro do terminal, execute flutter pub get e verifique se o emulador ou dispositivo está disponível.
